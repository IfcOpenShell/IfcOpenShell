Federation setFederationUnit · setFalseOrigin · setModelTransform

—
The red and green lines cross at viewer 0, 0, 0 and stay there. The false origin is the survey point: a smaller triad, and it can move. How federation works.
Set false origin turns off the automatic guess. The lines stay at 0, 0, 0. The small triad moves to the survey point, and the models shift so that coordinate is drawn on the crossing. Changing the unit does not convert the numbers; it changes what a number means.
