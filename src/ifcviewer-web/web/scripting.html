Camera getCamera · setCamera · setStandardView · viewAll

—
The sample load guesses a false origin and moves the amber survey marker off world 0, 0, 0. Target x, y, z are metres in the drawing frame that shifts with that marker. The Federation tab shows where the marker sits in the world. The long red and green lines stay on world 0, 0, 0. The RGB triad while you drag sits on the target.

Origin axes setOriginAxes

Metres either side of world 0, 0, 0, on X (red) and Y (green). The amber survey marker is the false origin. Click it for its coordinates, in the federation unit. The Federation tab edits it.

Federation setFederationUnit · setFalseOrigin · setModelTransform

—
The red and green lines cross at world 0, 0, 0 and stay there. Each model is placed in that world at its own coordinates. The false origin is the amber survey marker, and it can move. How federation works.
Set false origin turns off the automatic guess. The axes, the grid and the models stay where they are. The survey marker moves to the new point. Changing the unit does not convert the numbers; it changes what a number means.
Add a .ifcview to place it. The embedded sample has no source id.
Place model rotates it about the pivot, then slides it so point a lands on point b. b and the pivot are in the federation unit. You can set this before the file finishes loading.
