IfcOpenShell web viewer

Two examples of the same WebGPU viewer wasm (IfcViewerWeb.js), loaded through the small ifcviewer.js integration helper.

Fullscreen viewer →

The viewer fills the window with an overlay toolbar. Open/add .ifcview files, or auto-load remote models with ?model=URL.

Embedded viewer + JavaScript integration →

The viewer is a sized page element. Plain DOM outside it adds models (file or URL), lists the loaded models with streaming progress, and shows the GlobalId of whatever you click in the scene.
