IfcOpenShell web viewer

Examples of the same WebGPU viewer wasm (IfcViewerWeb.js), loaded through the small ifcviewer.js integration helper. Each viewer page loads sidecar format v19.

Fullscreen viewer →

The viewer fills the window with an overlay toolbar. Open/add .ifcview files, or auto-load remote models with ?model=URL. The Axes button draws X and Y on the floor, and Fog fades that floor into the background.

Embedded viewer + JavaScript integration →

The viewer is a sized page element. Plain DOM outside it adds models (file or URL), lists the loaded models with streaming progress, and shows the GlobalId of whatever you click in the scene.

Origin and federation →

What the axes origin is, what the false origin is, and how several models share one shift so large coordinates stay accurate.

Scripting API →

Drive the viewer from JavaScript: read and set the camera, read and set multi-selection, list every object with its GlobalId and model, toggle per-object visibility, override object colours, draw the floor’s X and Y axes, set the floor fog, and edit the federation unit, false origin, and per-model placement.
