Language support
================

Every code block in these guides is cut from a program that the test suite
runs. This page is generated from those code blocks, and lists which of them
exist in which language.

- **✓**: the example exists in that language.
- **to do**: the binding can do it, but the example has not been written yet.
  Contributions are welcome; the programs live in ``docs/ifcopenshell/examples``.
- **n/a**: the binding has no equivalent, for example because the feature is
  implemented in Python on top of the C++ core.
