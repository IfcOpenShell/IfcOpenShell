Language notes
==============

The guides in this section are shared between the three languages. The pages
below cover what only applies to one of them.

- :doc:`../ifcopenshell-cpp`: the ``IfcParse`` and ``IfcGeom`` libraries,
  schema namespaces, schema-agnostic parsing, and consuming IfcOpenShell from
  CMake.
- :doc:`../ifcopenshell-python`: the high level authoring API
  (``ifcopenshell.api``), the utility modules (``ifcopenshell.util``), and the
  selector syntax.
- :doc:`../ifcopenshell-js`: WebAssembly plugins, releasing native memory with
  ``dispose()``, and running in the browser.
