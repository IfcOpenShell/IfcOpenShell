Reference
=========

These pages describe the C++ core rather than one of the bindings, so they
apply to C++, Python, and JavaScript alike.

- :doc:`geometry_settings` lists every setting of the geometry iterator.
- :doc:`serialiser_settings` lists the settings of the geometry serialisers.
- :doc:`formats` compares the file formats IfcOpenShell reads and writes.
- :doc:`boolean_process` explains how boolean operations are evaluated.
