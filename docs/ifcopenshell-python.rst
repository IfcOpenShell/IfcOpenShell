IfcOpenShell-Python
===================

IfcOpenShell-Python provides Python bindings to the core IfcOpenShell C++
system, as well as high level analysis and authoring functions. All the
capabilities of the C++ core are available in Python.

IfcOpenShell is also available in :doc:`C++ <ifcopenshell-cpp>` and
:doc:`JavaScript / TypeScript <ifcopenshell-js>`. The :doc:`Hello, world!
<ifcopenshell/hello_world>` and :doc:`geometry processing
<ifcopenshell/geometry_processing>` guides are shared between the three
languages, with a tab for each language on every snippet. The guides in this
section cover what is specific to Python, such as the high level authoring API,
the utility modules, and the selector syntax.
